# Task 5 — MIA

This repository contains my solutions for **AI Team Training '27 — Task 5**.

## Tasks

### Task 1.1 — Uncover the Secret Hidden Word

Audio/DSP-based task focused on processing and analyzing audio signals to uncover a hidden word.

### Task 1.2 — Detect the Pattern

A classical computer vision task for detecting **red and blue balls** in images using OpenCV.

The solution uses:

* HSV color thresholding
* Morphological operations
* Contour detection
* Shape-based filtering
* Watershed segmentation
* Non-Maximum Suppression (NMS)
* YOLO-format labels
* Detection accuracy evaluation

### Task 1.3 — A Memo from 221B Baker Street

A computer vision / image-processing task involving the analysis of visual information to solve the given mystery.

## Technologies

* NumPy
* SciPy
* Matplotlib
* Classical Computer Vision
* Digital Signal Processing
